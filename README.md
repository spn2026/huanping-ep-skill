# huanping-ep-skill
环评文件智能编制技能：生成环评报告目录、章节初稿、表格与结论建议

## 包含内容
- .github/skills/ 环评技能文件（SKILL & prompt）

## 如何使用
1. 克隆仓库：
   git clone https://github.com/spn2026/huanping-ep-skill.git
2. 本地将 `.github/skills/` 中的 SKILL/Prompt 放入 VS Code 用户提示目录或项目的相应位置以启用。

## 技能文件（已包含）
- .github/skills/环评文件智能编制技能.SKILL.md
- .github/skills/环评文件智能编制技能.prompt.md
